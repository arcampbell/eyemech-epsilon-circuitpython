# Upstream

This repository ports `EyeMech_Epsilon/Code/NewFaceFollower.py` from the
adjacent EyeMech Epsilon repository to CircuitPython for a Seeed Studio XIAO
ESP32-S3 with a PCA9685 servo controller.

The mechanical files, assembly documentation, MicroPython firmware image, and
MicroPython-only library archives remain in the upstream repository. They are
not required to deploy this CircuitPython control program.
